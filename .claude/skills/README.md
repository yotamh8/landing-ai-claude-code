# Design skills

The skills in this folder are copied from [emilkowalski/skills](https://github.com/emilkowalski/skills)
(commit a81dbca, MIT license, see `LICENSE-emilkowalski`):

- `apple-design` – Apple's fluid interface and motion principles, translated for the web
- `emil-design-eng` – Emil Kowalski's design engineering philosophy (polish, components, animation decisions)
- `review-animations` – a strict review of animation and motion code (invoke with `/review-animations`)

The usage rules for this project are in `CLAUDE.md`, under "עיצוב".
